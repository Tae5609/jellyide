2. **Deployment config.** Add every auth/registration env var to `.env.example` and both compose files (as `${VAR:-default}`). In prod, `ADMIN_PASSWORD` uses `${ADMIN_PASSWORD:?set ADMIN_PASSWORD}`. Add a persistent volume note for the SAML cert dir.
3. **Smoke test.** `scripts/smoke-auth.sh` (`set -euo pipefail`, executable) builds the backend, runs it with a temp `DOWNLOAD_DIR`, `ADMIN_PASSWORD=smoke-pass-123` and `PORT=18080` (trap-kill), waits for the port, then asserts:
   - unauthenticated `/api/jobs` returns 401
   - providers returns 200
   - a bad login returns 401
   - a good login returns 200 and fills the cookie jar
   - `/me` returns 200 with username admin
   - a POST without `X-Requested-With` returns 403, and with it returns 200
   - `/media/jellyide.db` is not served (404/403)
   - register in the default mode returns 403
   - logout returns 204, then `/me` returns 401

   It prints PASS/FAIL per check and exits non-zero on any failure. Add it to CI after the Go build, and to `make check`.
